# Назначение

Модуль **Analytics** отвечает за сбор, обработку и предоставление аналитических данных платформы.

Модуль позволяет анализировать:

- эффективность обучения;
- поведение пользователей;
- качество образовательного процесса;
- использование функций платформы;
- работу AI;
- бизнес-метрики.

Analytics является системой анализа данных и не является источником истины для доменных данных.

Источники данных:

- Users;
- Tasks;
- Progress;
- Roadmap;
- AI;
- Notifications.

---

# Зона ответственности

Модуль отвечает за:

- сбор доменных событий;
- хранение аналитических событий;
- агрегацию данных;
- расчет метрик;
- построение отчетов;
- анализ поведения пользователей;
- анализ эффективности обучения;
- предоставление данных администраторам;
- предоставление данных другим сервисам.

---

# Что НЕ входит в ответственность

Модуль не отвечает за:

- хранение пользователей;
- хранение прогресса;
- хранение заданий;
- хранение теории;
- изменение бизнес-данных;
- управление обучением;
- построение roadmap;
- генерацию AI-рекомендаций;
- отправку уведомлений;
- авторизацию.

Analytics только читает данные и строит представления.

---

# Ограничения

Модуль не должен:

- изменять данные других модулей;
- использоваться как основное хранилище бизнес-данных;
- содержать бизнес-логику обучения;
- рассчитывать прогресс пользователя;
- заменять Progress;
- заменять AI;
- хранить секретные данные;
- создавать циклические зависимости.

# Компоненты

## Router

Назначение:

HTTP API интерфейс аналитики.

Ответственность:

- получение отчетов;

# Бизнес-правила

- Analytics получает данные только через события.
- Аналитические данные могут быть пересчитаны.
- Analytics не изменяет доменные данные.
- Каждое событие должно иметь источник.
- Метрики должны иметь определенное назначение.
- Отчеты строятся только на подтвержденных данных.

---

# Инварианты

- AnalyticsEvent всегда имеет тип.
- AnalyticsEvent всегда имеет источник.
- Метрика всегда имеет название.
- Метрика всегда имеет значение.
- Аналитика не изменяет состояние других модулей.
- Исторические события не изменяются.
