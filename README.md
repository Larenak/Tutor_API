# AI Tutor

Рабочий прототип платформы подготовки к ЕГЭ по профильной математике. Исходный код находится в `app`, документация — в `docs`, миграции Alembic — в `app/migrations`.

## Что можно проверить на сайте

- кабинет ученика и отдельный режим администратора;
- 19 учебных заданий по структуре ЕГЭ-2026 с официальной разбалловкой;
- roadmap со всеми темами и номерами 1–19, включая сложные №14 и №17;
- взаимные ссылки между roadmap, теорией и конкретными заданиями практики;
- анализ точности, слабых тем и индивидуальный план только по реальным ответам;
- AI-объяснение текущей страницы теории, три уровня подсказок и разбор фактической ошибки;
- результат полной диагностики после прохождения всех 19 типов заданий;
- публикация и снятие задания с публикации в admin-интерфейсе.

Учебный контент прототипа составлен по типам открытых материалов ФИПИ. Это не официальный КИМ. До появления реальных попыток аналитика остаётся пустой; демонстрационные ученики, проценты и прогнозы не подмешиваются. Тестовый балл ЕГЭ-2026 не рассчитывается до появления официальной шкалы перевода.

## Быстрый запуск сайта

1. Создать виртуальное окружение и установить зависимости: `pip install -e .[dev]`.
2. Проверить настройки в существующем `.env` (подключение `DATABASE_URL` не менялось).
3. Запустить приложение: `python -m uvicorn app.main:app --reload`.
4. Открыть [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Подключение AI-репетитора

Первый AI-контур поддерживает прямой DeepSeek API и модель DeepSeek через OpenRouter.
Без ключа сайт продолжает работать, а AI-блоки показываются в безопасном неактивном
состоянии.

1. Скопировать AI-переменные из `.env.example` в локальный `.env`.
2. Для прямого API указать `DEEPSEEK_API_KEY`; для OpenRouter —
   `OPENROUTER_API_KEY`. Ключ не хранится в репозитории и не возвращается API.
3. Ключ OpenRouter с префиксом `sk-or-`, ранее записанный в `DEEPSEEK_API_KEY`,
   распознаётся автоматически. Для модели из каталога OpenRouter используется
   `deepseek/deepseek-v4-flash-0731`.
4. После изменения ключа или модели перезапустить приложение.

Для OpenRouter запросы сортируются по пропускной способности провайдера, используют
автоматический fallback и до двух коротких повторов на временные 429/5xx или битый
JSON. Общий бюджет запроса ограничен 25 секундами, поэтому интерфейс получает
контролируемую ошибку вместо зависшего `Bad Gateway`. Ответы теории проверяются
строгой JSON-схемой и подбирают формат под вопрос: причина, алгоритм, определение,
простой разбор или пример. После объяснения ученик вводит ответ на самопроверку:
первая ошибка даёт подсказку, вторая показывает эталон и короткий разбор без нового
платного запроса к провайдеру.

ИИ получает только текущий раздел теории, текущую задачу или сохранённую неверную
попытку. Он не меняет прогресс, не открывает шаги roadmap и не подменяет проверенные
ответы каталога.

Учебные API пока хранят реальные попытки текущей сессии в памяти процесса, поэтому при перезапуске сервера они сбрасываются. Auth/Users продолжают работать с PostgreSQL как раньше.
