# Назначение

Модуль **Roadmap** отвечает за создание, хранение и управление учебными маршрутами подготовки пользователя.

Roadmap определяет:

- порядок изучения тем;
- этапы подготовки;
- рекомендуемую последовательность обучения;
- связь между темами, теорией и практикой;
- структуру подготовки к экзамену.

Модуль является владельцем логики учебного пути, но не отвечает за фактическое выполнение обучения пользователем.

Roadmap использует данные:

- Topics — структура знаний;
- Tasks — практика;
- Progress — текущее состояние пользователя;
- AI — адаптация и рекомендации.

---

# Зона ответственности

Модуль отвечает за:

- создание учебных маршрутов;
- хранение структуры подготовки;
- управление этапами подготовки;
- управление порядком изучения тем;
- создание связей между этапами и темами;
- хранение целей подготовки;
- хранение шаблонных roadmap;
- предоставление плана обучения пользователю;
- адаптацию маршрута на основе входных данных.

---

# Что НЕ входит в ответственность

Модуль не отвечает за:

- хранение тем;
- хранение теории;
- хранение заданий;
- хранение прогресса;
- проверку решений;
- генерацию AI-ответов;
- анализ ошибок;
- авторизацию пользователей;
- платежи.

Эти функции находятся в других модулях.

---

# Ограничения

Модуль не должен:

- изменять Topics;
- изменять Tasks;
- изменять Progress напрямую;
- самостоятельно проверять знания пользователя;
- самостоятельно генерировать AI-рекомендации;
- хранить образовательный контент;
- хранить историю решений;
- выполнять бизнес-логику других модулей;
- создавать циклические зависимости.

# Основные сущности

## Roadmap

Учебный маршрут подготовки пользователя.

Содержит:

- пользователя;
- предмет;
- цель;
- дату создания;
- статус.

Пример:

```

ЕГЭ Математика

Цель:  
80+ баллов

Этап:  
Изучение базы

```

---

## RoadmapStage

Этап подготовки.

Пример:

```

1. Повторение базы
    
2. Изучение сложных тем
    
3. Решение вариантов
    
4. Финальная подготовка
    

```

---

## RoadmapTopic

Связь этапа с темой.

Определяет:

- какие темы изучаются;
- порядок;
- важность.

---

## RoadmapTemplate

Шаблон подготовки.

Используется для:

- стандартных программ;
- разных экзаменов;
- разных целей.

# Бизнес-правила

- Пользователь может иметь несколько roadmap для разных предметов.
- Один roadmap относится только к одному предмету.
- Этапы имеют определенный порядок.
- Тема может находиться только в одном месте roadmap.
- Следующий шаг определяется текущим состоянием обучения.
- Изменение структуры roadmap не изменяет историю прогресса.
- Удаление roadmap не удаляет данные обучения.

---

# Инварианты

- Roadmap всегда принадлежит пользователю.
- Roadmap всегда связан с предметом.
- Каждый этап принадлежит одному roadmap.
- Порядок этапов уникален.
- Тема внутри roadmap не дублируется.
- Roadmap имеет статус.
- Roadmap не хранит результаты обучения.
