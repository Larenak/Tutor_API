# Материалы ФИПИ для прототипа

Архив `ma_11_2026.zip` загружен 23 августа 2026 года с официального сайта ФИПИ:

<https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2026/ma_11_2026.zip>

В каталоге `documents` находятся извлечённые демоверсии профильного и базового уровней и кодификатор ЕГЭ-2026 по математике.

В продуктовый банк включены не копии официальных КИМ, а адаптированные учебные аналоги, привязанные к структуре, разбалловке и кодам тем ФИПИ.
