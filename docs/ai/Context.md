# Назначение

Модуль **Context** отвечает за управление контекстом, который используется AI-компонентами платформы при генерации ответов.

Контекст представляет собой набор данных, необходимых AI для понимания ситуации пользователя и выполнения задачи.

Модуль обеспечивает AI информацией о:

- пользователе;
- уровне знаний;
- текущем обучении;
- истории взаимодействия;
- целях подготовки;
- ограничениях.

---

# Цели

Основные цели модуля:

- сделать ответы AI персонализированными;
- обеспечить AI необходимыми данными;
- контролировать объём передаваемой информации;
- отделить управление контекстом от AI-агентов;
- повысить качество генерации ответов.

---

# Ответственность

Модуль отвечает за:

- сбор контекста пользователя;
- формирование AI Context;
- управление размером контекста;
- приоритизацию данных;
- очистку устаревшей информации;
- передачу контекста AI-агентам;
- управление краткосрочной и долгосрочной памятью.

---

# Не отвечает за

Модуль не отвечает за:

- хранение исходных данных пользователя;
- хранение прогресса обучения;
- создание AI-ответа;
- выбор AI-агента;
- генерацию embeddings;
- поиск знаний через RAG;
- бизнес-логику обучения.

# Компоненты

## Context Builder

Основной компонент формирования контекста.

Отвечает за:

- получение данных из системы;
- объединение информации;
- фильтрацию данных;
- подготовку структуры для AI.

---

## Context Storage

Хранилище временного и долгосрочного контекста.

Возможные данные:

- история обучения;
- предпочтения ученика;
- предыдущие ошибки;
- текущие цели.

---

## Context Manager

Управляет жизненным циклом контекста.

Отвечает за:

- создание контекста;
- обновление;
- удаление;
- оптимизацию размера.

# Типы Context

## User Context

Информация о пользователе.

Пример:

```json
{
  "level": "middle",
  "goal": "ЕГЭ 90+",
  "preferred_style": "examples"
}
````

Используется для персонализации.

---

## Learning Context

Контекст обучения.

Содержит:

- изучаемые темы;
    
- прогресс;
    
- слабые места;
    
- результаты заданий.
    

Пример:

```json
{
  "current_topic": "Производная",
  "weak_topics": [
    "Правила дифференцирования"
  ]
}
```

---

## Conversation Context

Контекст текущего взаимодействия.

Содержит:

- последние сообщения;
    
- текущую задачу;
    
- предыдущие вопросы.
    

Используется для поддержания диалога.

---

# Context Priority

Не все данные имеют одинаковую важность.

Приоритет:

## Высокий

- текущая задача;
    
- ошибки ученика;
    
- цель обучения.
    

## Средний

- история обучения;
    
- уровень знаний.
    

## Низкий

- старые взаимодействия;
    
- неактуальные данные.

# Security

Необходимо:

- ограничивать доступ AI к данным пользователя;
    
- передавать только необходимые данные;
    
- удалять чувствительную информацию;
    
- контролировать сохранение памяти;
    
- предотвращать утечки контекста.
    

---

# Logging

Логируются:

- тип созданного контекста;
    
- размер контекста;
    
- использованные источники;
    
- время формирования;
    
- ошибки.
    

Не логируются:

- персональные данные;
    
- содержимое приватных сообщений без необходимости.
    

---

# Evaluation

Качество контекста оценивается по:

- релевантности переданных данных;
    
- влиянию на качество ответа;
    
- размеру контекста;
    
- скорости формирования.
    

Метрики:

- Context Relevance;
    
- Token Efficiency;
    
- Response Improvement.
    

---

# Extensibility

Модуль должен позволять:

- добавлять новые типы памяти;
    
- подключать новые источники данных;
    
- использовать разные стратегии формирования контекста;
    
- добавлять персональные настройки AI;
    
- масштабировать AI-персонализацию.
    

---

# Definition of Done

Модуль считается реализованным, если:

- реализована система формирования контекста;
    
- есть разделение short-term и long-term памяти;
    
- AI-агенты получают нужные данные;
    
- реализована оптимизация размера контекста;
    
- настроена интеграция с бизнес-модулями;
    
- обеспечена безопасность данных;
    
- реализовано логирование.
