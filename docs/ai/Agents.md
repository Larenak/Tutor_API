# Назначение

Модуль **Agents** отвечает за проектирование, управление и выполнение специализированных AI-агентов внутри образовательной платформы.

AI-агент представляет собой автономный компонент, который использует языковые модели, prompts, контекст пользователя и дополнительные инструменты для выполнения конкретной образовательной задачи.

Модуль определяет:

- какие AI-агенты существуют в системе;
- какие задачи они выполняют;
- какие данные используют;
- какие инструменты могут вызывать;
- как взаимодействуют между собой.

---

# Цели

Основные цели модуля:

- разделить AI-функциональность на специализированные компоненты;
- повысить качество ответов за счёт узкой специализации агентов;
- обеспечить расширяемость AI-системы;
- упростить развитие новых AI-возможностей;
- отделить AI-поведение от бизнес-логики приложения.

---

# Ответственность

Модуль отвечает за:

- описание AI-агентов;
- управление жизненным циклом агентов;
- определение задач каждого агента;
- настройку используемых prompts;
- определение доступных инструментов;
- маршрутизацию запросов между агентами;
- контроль взаимодействия агентов.

---

# Не отвечает за

Модуль не отвечает за:

- хранение пользовательских данных;
- хранение прогресса ученика;
- хранение учебных материалов;
- управление подписками;
- бизнес-решения платформы;
- генерацию самих языковых моделей;
- хранение истории общения.

---

# Архитектура

Agents является частью AI-слоя системы.

Общий поток:

```

User Request  
|  
↓  
AI Service  
|  
↓  
Agent Router  
|  
↓  
Selected Agent  
|  
├── Prompt  
|  
├── Context  
|  
├── RAG  
|  
└── Tools  
|  
↓  
LLM  
|  
↓  
Response

````

Каждый агент является специализированным обработчиком определённого типа задач.

# Компоненты

## Agent Definition

Описание AI-агента.

Содержит:

- название;
- назначение;
- доступные действия;
- используемый prompt;
- требования к контексту;
- ограничения.

Пример:

```json
{
  "name": "math_tutor",
  "purpose": "Объяснение математических тем",
  "prompt": "math_tutor_v1"
}
````

---

## Agent Router

Компонент выбора подходящего агента.

Отвечает за:

- анализ запроса;
    
- определение типа задачи;
    
- выбор агента;
    
- передачу необходимых данных.
    

Пример:

```
Пользователь:
"Почему я получил ошибку?"

Router:
→ Checker Agent
```

---

## Agent Executor

Компонент выполнения агента.

Отвечает за:

- сбор контекста;
    
- вызов prompt;
    
- обращение к модели;
    
- обработку результата.

# AI Agents

## Tutor Agent

### Назначение

Персональный AI-репетитор.

### Ответственность

- объяснение теории;
    
- разбор ошибок;
    
- помощь в понимании темы;
    
- адаптация объяснения под уровень ученика.
    

### Использует:

- Theory Module;
    
- Context;
    
- RAG;
    
- Progress.
    

---

## Solver Agent

### Назначение

Помощник при решении задач.

### Ответственность

- анализировать условие задачи;
    
- показывать ход решения;
    
- объяснять методы;
    
- указывать ключевые шаги.
    

### Ограничение

Не должен просто выдавать ответ без объяснения.

---

## Checker Agent

### Назначение

Проверка решений ученика.

### Ответственность

- анализировать ответ;
    
- находить ошибки;
    
- объяснять причины ошибок;
    
- оценивать качество решения.
    

Использует:

- Tasks Module;
    
- правильные решения;
    
- критерии проверки.
    

---

## Planner Agent

### Назначение

Создание персонального плана подготовки.

### Ответственность

- анализировать текущий уровень ученика;
    
- определять слабые темы;
    
- предлагать последовательность изучения;
    
- корректировать roadmap.
    

Использует:

- Progress;
    
- Analytics;
    
- Topics.
    

---

## Recommendation Agent

### Назначение

Персональные рекомендации.

### Ответственность

- выбирать следующие задания;
    
- рекомендовать темы;
    
- предлагать повторение материала.
    

Использует:

- историю обучения;
    
- ошибки;
    
- прогресс.
    

---

## Analytics Agent

### Назначение

AI-анализ обучения.

### Ответственность

- выявлять закономерности;
    
- анализировать эффективность подготовки;
    
- создавать отчёты.

# Input

Agents получают:

- пользовательский запрос;
    
- выбранную задачу;
    
- контекст пользователя;
    
- учебные данные;
    
- результаты предыдущих действий;
    
- дополнительные документы.
    

Пример:

```json
{
  "agent": "tutor",
  "user_id": "123",
  "topic": "Производная",
  "level": "beginner"
}
```

---

# Output

Агент возвращает:

- ответ пользователю;
    
- структурированные данные;
    
- рекомендации;
    
- следующие действия.
    

Пример:

```json
{
  "answer": "Производная показывает скорость изменения функции",
  "recommendations": [
    "Повторить правила дифференцирования"
  ]
}
```

---

# Agent Communication

Взаимодействие агентов происходит через AI Service.

Пример:

```
Planner Agent

определил проблему

        ↓

Recommendation Agent

подобрал задания

        ↓

Tutor Agent

объяснил тему
```

Агенты не должны напрямую обращаться друг к другу без управляющего слоя.

---

# Context Management

Каждый агент получает только необходимый контекст.

Пример:

Tutor Agent:

```
Нужно:
- уровень ученика;
- тема;
- ошибки.

Не нужно:
- платежные данные;
- настройки аккаунта.
```

# Security

Необходимо:

- ограничивать доступ агентов к данным;
    
- фильтровать пользовательский ввод;
    
- защищать системные инструкции;
    
- предотвращать выполнение опасных действий;
    
- контролировать доступ к инструментам.
    

---

# Logging

Логируются:

- агент;
    
- версия агента;
    
- использованный prompt;
    
- модель;
    
- время выполнения;
    
- ошибки;
    
- качество ответа.
    

Не логируются:

- лишние персональные данные;
    
- чувствительная информация пользователя.
    

---

# Evaluation

Оценка качества агентов проводится по:

- правильности ответа;
    
- полезности объяснения;
    
- способности адаптироваться;
    
- количеству ошибок;
    
- удовлетворённости пользователя.
    

Методы:

- автоматические тесты;
    
- экспертная проверка;
    
- пользовательская обратная связь.
    

---

# Extensibility

Модуль должен позволять:

- добавлять новые агенты;
    
- подключать новые инструменты;
    
- менять модели;
    
- расширять сценарии обучения;
    
- создавать новые AI-роли.
    

---

# Definition of Done

Модуль считается реализованным, если:

- создана система регистрации AI-агентов;
    
- реализован Agent Router;
    
- агенты используют Prompts;
    
- агенты получают Context;
    
- настроена интеграция с RAG;
    
- реализовано логирование;
    
- есть система оценки качества;
    
- описаны ограничения каждого агента.
