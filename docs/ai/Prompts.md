# Назначение

Модуль **Prompts** отвечает за проектирование, хранение, управление и использование текстовых инструкций (prompts) для взаимодействия AI-компонентов платформы с языковыми моделями.

Prompts являются управляющим слоем между бизнес-логикой платформы и AI-моделями.

Модуль определяет:

- какие инструкции получает AI;
- в каком формате AI должен отвечать;
- какие правила поведения применяются;
- какие данные необходимо учитывать при генерации ответа.

---

# Цели

Основные цели модуля:

- обеспечить единый подход к созданию AI-инструкций;
- повысить качество и стабильность ответов AI;
- разделить AI-логику и бизнес-логику приложения;
- обеспечить версионирование промптов;
- позволить улучшать AI без изменения основного кода приложения.

---

# Ответственность

Модуль отвечает за:

- хранение шаблонов промптов;
- управление версиями промптов;
- определение ролей AI;
- формирование структуры сообщений для LLM;
- передачу контекста в AI-запросы;
- настройку параметров генерации;
- тестирование качества промптов;
- документирование поведения AI.

---

# Не отвечает за

Модуль не отвечает за:

- выбор и загрузку AI-модели;
- хранение пользовательских данных;
- хранение истории диалогов;
- поиск информации через RAG;
- выполнение бизнес-операций;
- анализ прогресса ученика;
- принятие решений вместо бизнес-модулей.

# Компоненты

## Prompt Template

Шаблон инструкции для AI.

Содержит:

- роль AI;
- задачу;
- ограничения;
- формат ответа;
- правила поведения.

Пример:

```

Ты являешься AI-репетитором по математике.

Твоя задача:  
объяснить тему ученику простым языком.

Правила:

- не давать ответ сразу;
    
- сначала объяснить идею;
    
- учитывать уровень ученика.
    

```

---

## Prompt Manager

Компонент управления промптами.

Отвечает за:

- поиск нужного промпта;
- выбор версии;
- сбор параметров;
- подготовку запроса к модели.

---

## Prompt Versioning

Система версий промптов.

Позволяет:

- изменять поведение AI постепенно;
- сравнивать версии;
- откатывать изменения;
- проводить эксперименты.

Пример:

```

math_tutor_prompt

v1:  
Базовое объяснение

v2:  
Добавлена адаптация под уровень ученика

```

# Типы Prompts

## System Prompt

Главная инструкция для модели.

Определяет:

- роль AI;
- правила поведения;
- ограничения.

Пример:

```

Ты опытный преподаватель ЕГЭ.  
Объясняй материал понятно и последовательно.

```

---

## Task Prompt

Инструкция для конкретного действия.

Пример:

```

Объясни решение задачи по квадратным уравнениям.

```

---

## Context Prompt

Передача дополнительной информации.

Например:

```

Ученик:

- уровень: средний
    
- ошибки:
    
    - дискриминант
        
    - преобразование выражений
        

```

---

## Evaluation Prompt

Используется для оценки качества ответа AI.

Пример:

```

Оцени объяснение по критериям:

- правильность;
    
- понятность;
    
- соответствие уровню ученика.
    

````

# Input

Prompts получает:

- тип AI-задачи;
- идентификатор агента;
- пользовательский контекст;
- данные обучения;
- данные из RAG;
- параметры генерации.

Пример:

```json
{
  "agent": "tutor",
  "topic": "Квадратные уравнения",
  "student_level": "medium",
  "weaknesses": [
    "дискриминант"
  ]
}
````

---

# Output

Модуль возвращает:

- подготовленный prompt;
    
- структуру сообщений;
    
- параметры генерации.
    

Пример:

```json
{
  "messages": [
    {
      "role": "system",
      "content": "Ты AI-репетитор..."
    },
    {
      "role": "user",
      "content": "Объясни тему..."
    }
  ]
}
```

# Context Management

Prompts работают совместно с системой контекста.

В prompt могут передаваться:

- профиль ученика;
    
- уровень знаний;
    
- история ошибок;
    
- текущий прогресс;
    
- цель обучения;
    
- результаты прошлых попыток.
    

Контекст должен быть:

- ограниченным;
    
- релевантным;
    
- безопасным;
    
- оптимизированным по размеру.

# Prompt Engineering

Основные принципы:

## Clear Instructions

Инструкция должна быть однозначной.

Плохо:

```
Объясни тему.
```

Хорошо:

```
Объясни тему ученику 9 класса.
Используй простые примеры.
Не используй сложные термины без объяснения.
```

---

## Structured Output

Ответ AI должен иметь предсказуемый формат.

Например:

```json
{
  "explanation": "",
  "mistakes": [],
  "recommendations": []
}
```

---

## Role Assignment

Каждый AI-компонент получает конкретную роль:

- преподаватель;
    
- проверяющий;
    
- планировщик;
    
- аналитик.

# Security

Необходимо:

- скрывать внутренние системные инструкции;
    
- контролировать пользовательский ввод;
    
- защищать prompts от prompt injection;
    
- ограничивать доступ к редактированию.
    

---

# Logging

Логируются:

- идентификатор промпта;
    
- версия;
    
- используемый агент;
    
- модель;
    
- время выполнения;
    
- результат оценки.
    

Не логируются:

- персональные данные без необходимости;
    
- приватная информация пользователя.
    

---

# Evaluation

Качество промптов оценивается по:

- точности ответа;
    
- полезности объяснения;
    
- соответствию уровню ученика;
    
- стабильности результата;
    
- количеству ошибок.
    

Методы:

- автоматическая оценка;
    
- тестовые наборы задач;
    
- пользовательская обратная связь.

# Extensibility

- создавать новые AI-роли;
    
- подключать новые модели;
    
- проводить эксперименты;
    
- использовать разные стратегии генерации.
    

---

# Definition of Done

Модуль считается реализованным, если:

- существует система хранения промптов;
    
- реализовано версионирование;
    
- AI Service умеет получать нужные prompts;
    
- есть документация по каждому prompt;
    
- реализовано логирование использования;
    
- есть механизм оценки качества;
    
- обеспечена защита от prompt injection.
